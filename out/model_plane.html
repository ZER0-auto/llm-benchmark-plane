坐标是「相对基准模型的能力倍数」，1.0 = DeepSeek V4.1 Flash 1017；在场榜上还钉了 0 点 = MiniMax-M3（零点高的榜按动态范围降权，不做放大硬凑）。
每个来源只取该模型最新一次测量值，不跨月取中位——模型和题库都在迭代，跨版本数值不可比。
严格版本内比较：致知按月榜切版本，版本内必须含基准 DeepSeek V4.1 Flash 1017，否则整版丢弃；屎山是“难度向上加题、模型从低到高逐级通过”的阶梯赛，整块算一个版本。
缺 1017 的榜（ProofBench / MysteryMechanism / SkillsBench / IOI / 屎山）用 DeepSeek V4.1 Flash 作链式锚点：先在其他榜测出它相对 1017 的两个因子（P 0.917 / X 0.760），再按该榜成分 α 折算出该榜的等效基准。屎山榜单写的 DeepSeek Flash 经核实就是这个 V4.1 Flash，不是 1017。
每个来源带一个 P 成分 α：r ≈ α·P + (1−α)·X，按可信度 w 做岭回归解出每个模型的 P 与 X，不在源与源之间硬切轴。
P 与 X 被限制在该模型观测比值的区间内：无约束解会外推（某模型全部榜最高只 0.94，回归却能给出 X=1.2），钳位后的点会在 tooltip 里标出拟合 RMSE 与比值范围。
权重已按留一残差校准（scripts/calibrate_weights.py，口径见 METHOD §15）：注册表里 weight_prior 是初猜、weight_cal 是校准值，管道优先用后者；公开源占比按上限 0.20 配平。
Artificial Analysis 只用分项（HLE / AA-LCR / CritPT / SciCode / AutomationBench），不使用它的综合指数；Omniscience 因分数跨度过大暂不计分。
档位：取两轴中较高者；边界每轮由数据自己算（自然断裂，不写死数值），本轮 M0 ≥1.260、M1 ≥0.597、M2 ≥-0.134，其余 M3（相邻边界间距 0.663 / 0.731）
若某模型的来源全是纯 P 或纯 X（α=1 或 0），另一轴留空，画在 P=X 对角线上并用空心标记（○ 仅 P、◇ 仅 X）；当前混合模型下没有这种点。两轴覆盖度都低于 35% 的点画成虚线环并淡显标签（本轮 13 个），数值靠先验撑住、只作参考；不剔除，因为单一来源本身也是证据。本轮守卫剔除：medscribe、srebench、terminal-bench-science（等效基准超过该榜满分、或不足满分 5%，比值失真）；接近满分的榜：legal_bench、shishan（比值放大，谨慎解读）；ProgramBench 不在来源表中（分数区间 0–18.5 过窄）。表格与 tooltip 里的区间来自源级 bootstrap（1000 次有放回重采样，单位=计分源 27 个，seed=20261026，取 5-95% 分位）——它是「换一批榜会差多少」的跨榜组成敏感性，不是同一批数据的置信区间：每次重采样平均只有 17.3 个源在场，锚点/版本切分/零点阈值/λ/档位边界都不在区间里。区间宽度中位 P 0.459 / X 0.54（本轮相邻边界间距 0.663 / 0.731），末位小数是蒙特卡洛噪声。档位稳定率（分母=全部重采样）中位 0.85，分档看是 M0 0.90、M1 0.96、M2 0.68、M3 0.68；稳定率 <0.5 的有 2 个（glm5.3flash、k2horizon375ba23b），多数派与标出档位不同的 2 个（glm5.3flash、k2horizon375ba23b），证据在场率 <90% 的 14 个（只有一个来源的模型会在约三分之一的重采样里完全没有坐标，这类点的区间宽度为 0 不代表确定，只代表该榜单独决定它），点估计落在自己区间外的 0 处（应为 0）。 悬停看各源比值、区间与档位稳定率。
